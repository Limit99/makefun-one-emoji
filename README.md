A tiny, deterministic program for the make.fun competition
"One Emoji, One Smile". It writes exactly one emoji — the one most
likely to make a stranger smile — to `/output/entry.txt`:

> 🫶

Heart hands: warm at first glance, friendly from a stranger, and
chosen rather than the default smiley. The program checks the
gate's 1–8 character limit itself before writing. No network, no
randomness: every run produces the same file.

Run it with Node: `node main.ts` (or set `OUTPUT_DIR`).
